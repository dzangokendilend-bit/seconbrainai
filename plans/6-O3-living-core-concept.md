# Phase 6-O3 — концепт «Живое ядро» (регистрация как сборка мозга)

> Источник идей: registration-motion-concepts.md (К1 «Ритуал запуска мозга» + К3
> «Storyboard» + К5 «Геймификация», без Lottie/конфетти/К2/К4).
> Проблема: слайдер-презентация красивая, но сами 7 шагов визарда — сухая анкета.
> Решение: шаги визарда превращаются в непрерывную сцену сборки цифрового мозга.

## 1. Центральная идея

В визарде живёт **ядро** — глобус «М» с орбитами-нейронами, которое переживает
все 7 шагов (не пересоздаётся при перерисовке `#wz`). Каждый шаг пользователя
физически меняет ядро:

| Шаг | Действие пользователя | Реакция ядра |
|-----|----------------------|--------------|
| 2 | выбор «откуда узнал» | нейрон-точка летит из чипа в ядро, ядро вспыхивает |
| 3 | ввод юзернейма | ядро «прислушивается» (наклон к полю в фокусе) |
| 3 | blur заполненного поля | точка летит в ядро, пульс |
| 3 | загрузка аватара | аватар появляется внутри ядра на 1.2s и растворяется |
| 4 | выбор модели | вокруг ядра закрепляется цветное кольцо-орбита |
| 4 | ползунок нагрузки 1–10 | интенсивность свечения ядра (CSS-переменная) |
| 5 | включение модуля | спутник вылетает из переключателя и встаёт на орбиту ядра |
| 5 | выключение модуля | спутник снимается с орбиты и растворяется |
| 6 | ввод ключа ≥8 символов | «канал связи»: мини-спутник летит к ядру |
| 7 | фокус пароля | ядро обводится золотым «щитом» |
| финал | complete | спутники слетаются в ядро → вспышка → чат (launchFinale) |

К финалу ядро визуально «собрано»: кольцо модели + до 3 спутников-модулей +
каналы ключей. Запуск = ядро поглощает всё и вспыхивает.

## 2. Композиция шага

- `#scr-wizard` получает двухзонный каркас: слева (на узких экранах — сверху)
  **ядро-сцена** `#wcore` (глобус 96px, 2 орбиты с нейронами, слоты спутников,
  мягкое свечение), справа — существующая карточка шага `#wz`.
- `#wcore` создаётся один раз в `renderWizard()` и живёт вне `#wz`, поэтому
  переживает перерисовку шагов — непрерывность сцены.
- Ядро «дышит» (scale 1↔1.03, 4s) + лёгкий parallax от мыши (механика уже есть
  в слайдере — переиспользуем `--mx/--my`).

## 3. Анимации (детально)

### 3.1. Каскадное появление формы (все шаги)
Элементы `#wz` (label, input, .mod, .chip-бокс, .row) появляются stagger-каскадом:
`opacity 0 → 1`, `translateY(10px) → 0`, 0.3s ease-out, задержка 55ms на элемент
(через `:nth-child` в CSS, без JS). Ядро при смене шага делает «взгляд»:
scale 1 → 1.07 → 1 за 0.5s + короткий всплеск свечения.

### 3.2. Полёты «действие → ядро» (шаги 2, 3, 6)
Единый хелпер `flyToCore(fromEl, cls)`:
- точка 8px (цвет по классу: нейрон — синий, канал — золотой) появляется в
  центре элемента-источника (fixed, координаты из getBoundingClientRect);
- полёт 650ms, cubic-bezier(.45,-.1,.55,1) — лёгкий «замах» назад в начале;
- в конце — `coreFlash()`: ядро scale 1.09 + glow на 450ms, точка растворяется.
Одновременно максимум 3 точки (старые удаляются).

### 3.3. «Прислушивание» (шаг 3)
Пока `#w-user` в фокусе — ядро наклоняется в сторону формы: `rotate(3deg)
translateX(4px)`, transition 0.4s. При blur — возвращается. Заполненное поле на
blur дополнительно запускает `flyToCore`.

### 3.4. Аватар в ядре (шаг 3)
После чтения файла аватар (dataURL) вставляется в ядро как круглая маска
(56px, поверх глобуса): scale-in 0.3s → живёт 1.2s с медленным zoom → fade-out
0.4s. Глобус под ним на это время приглушается (brightness .5).

### 3.5. Кольцо модели (шаг 4)
При выборе модели вокруг ядра разворачивается кольцо (border 1px, цвет модели
из палитры проектов): `scale .6 → 1` + fade за 0.45s. Смена модели — старое
кольцо растворяется, новое разворачивается. Ползунок нагрузки пишет
`--core-glow: 0..1` → свечение ядра `drop-shadow(0 0 calc(6px + 18*var(--core-glow)) ...)`
и скорость дыхания (animation-duration 4s → 2.2s на максимуме).

### 3.6. Спутники-модули (шаг 5)
`addSatellite(name)`: точка с подписью вылетает из переключателя (flyToCore с
остановкой на орбите), занимает слот на орбите ядра (3 позиции: 0°/120°/240°,
radius 74px) и остаётся: лёгкое вращение вместе с орбитой, подпись 10px.
`removeSatellite(name)`: обратный полёт к переключателю + fade. Состояние
спутников сбрасывается при перезаходе в визард (черновик восстанавливает
выбор — при рендере шага 5 спутники выставляются мгновенно, без полёта).

### 3.7. Каналы ключей (шаг 6)
Когда длина значения поля ≥8 — поле один раз испускает золотую точку
(`flyToCore(input, 'chan')`), у ядра загорается мини-дуга (3 коротких штриха
по верху ядра, stagger). Стираешь ключ — дуга гаснет.

### 3.8. Щит пароля (шаг 7)
Фокус `#w-pass` — вокруг ядра проявляется золотое пунктирное кольцо
(dash-rotation 6s). Blur — тает. Успешный complete — финал (3.9).

### 3.9. Финальный запуск (усиление launchFinale)
Перед существующей сценой: спутники и кольцо слетаются в ядро (300ms),
ядро сжимается (scale .9) → вспышка → существующий `#finale` (глобус светом,
ускоренные орбиты, «Мозг запущен»).

### 3.10. Микро-детали
- Фокус поля: label → акцентный цвет, поле translateY(-1px) + свечение тени.
- Прогресс-бар: по заполненной части бежит искра (градиентная полоска,
  background-position анимация 1.6s loop).
- Кнопка «Далее»: hover — ядро слегка «тянется» (translate 2px к низу формы).

## 4. Ограничения
- Только CSS keyframes/transitions + точечный JS (координаты полётов, классы).
- `prefers-reduced-motion`: полёты/пульсы/каскад → мгновенные состояния, остаётся fade.
- Никаких новых библиотек; style.css не трогаем — всё в monica.css.
- Ядро одно на визард; в слайдере (шаг 1) остаётся своя сцена — `#wcore`
  показывается только на шагах 2–7.

## 5. Файлы
- `app/web/index.html` — контейнер `#wcore` рядом с `#wz`.
- `app/web/app.js` — renderWizard (создание ядра), хелперы coreFly/coreFlash/
  addSatellite/removeSatellite/setCoreGlow, хуки шагов 2–7, усиленный finale.
- `app/web/monica.css` — сцена ядра, орбиты, спутники, каскад, фокус-эффекты,
  искра прогресса, щит, reduced-motion.
- `tools/ui_smoke.js` — обновить проверки (глиф → ядро), добавить: спутник
  модуля на орбите, кольцо модели, glow от ползунка, канал ключа.
