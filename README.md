# Моника 1.0

Веб-сервис личного ИИ: онбординг, модули (Википедия, Telegram-бот,
Полная аналитика), чат и терминал для работы с личным second-brain.

## Запуск (dev)

    python app/server.py
    -> http://127.0.0.1:8900

## Структура

- app/ — код (auth, onboarding, keys, modules, terminal, providers)
- app/web/ — фронтенд (html/js/css, без сборки)
- data/users/<id>/ — vault и профиль пользователя (вне git)
- config.json — порт, пароль аналитики, машинный секрет (вне git)

## Принципы

- stdlib-only Python + vanilla JS, без сборки.
- Ключи API шифруются машинным секретом, в UI маскируются.
- Терминал: белый список операций над vault пользователя, пути чинятся сервером.
- Полная аналитика: выключена по умолчанию, пароль в config.json.

Смежный проект: ../second-brain/ — личные знания автора, кодом не является.
